# ふりかえりルーレット（furikaeriroulette）

学習や一日の「ふりかえり」のテーマをルーレット（ランダム抽選）で決め、そのテーマで短いふりかえりメモを残せる小さなツールです。自己調整学習のふりかえり習慣を、軽く・迷わず回すための小物という位置づけです。

## 機能

- **ルーレット抽選**：「回す」ボタンを押すと、登録されているテーマ（ふりかえりの質問）からサーバー側でランダムに1件を選び、結果を大きく表示します。テーマが0件のときは抽選できません。
- **メモの保存**：当たったテーマと一緒に、短いふりかえりメモを保存できます。保存日時は日本時間（JST）で記録されます。
- **履歴表示**：保存したメモはテーマ・日時つきで新しい順に一覧表示され、1件ずつ削除できます。
- **テーマの管理**：テーマは自分で追加・削除できます。初回起動時は、既定のテーマ9件（「今日いちばん集中できたのはいつ？」など）が自動で登録されます。

データは SQLite に保存します。DB のパスは環境変数 `FURIKAERI_DB` で変更できます。

## 使い方

1. トップページの「回す」ボタンを押して、今日のふりかえりテーマを引きます。
2. テーマに沿って短いメモを書き、「保存」ボタンで残します。
3. 履歴一覧で過去のふりかえりを眺めます。不要なメモは「削除」ボタンで消せます。
4. テーマを増やしたいときは「テーマを追加」フォームから登録します（既定のテーマも削除できます）。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```
